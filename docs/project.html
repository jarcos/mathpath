Project Description

MathPath is a single-user, fully offline desktop application that teaches mathematics in a structured ladder — starting at pre-university level and building toward the linear algebra, calculus and statistics that underpin machine learning and deep learning.

Each big subject is scoped to a ~30-day adaptive study plan. Lessons combine explanations, worked examples and live function graphs; exercises are checked symbolically (so 1/2, 0.5 and 2/4 all count as correct) and reveal step-by-step solutions on demand. All content is bilingual (English / Spanish) and pre-generated at build time, with curriculum sourced from UOC engineering-maths modules and verified by an automated mathjs gate. Progress, attempts and plans live locally in SQLite — no accounts, no network.
